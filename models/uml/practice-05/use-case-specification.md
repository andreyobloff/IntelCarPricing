# Спецификация вариантов использования

| Код | Вариант использования | Актор | Результат |
|---|---|---|---|
| UC1 | Загрузить продажи | Система продаж | История продаж доступна |
| UC2 | Загрузить каталог | Каталог продукции | Товары доступны для сопоставления |
| UC3 | Получить рыночные цены | Источник рыночных цен | Получены конкурентные цены |
| UC4 | Проверить качество данных | Менеджер | Данные допущены к расчёту |
| UC5 | Рассчитать рекомендованную цену | Менеджер | Сформирована рекомендация |
| UC6 | Получить объяснение рекомендации | Менеджер | Сформировано обоснование |
| UC7 | Согласовать цену | Бизнес-эксперт | Цена утверждена или отклонена |
| UC8 | Опубликовать цену | Менеджер | Цена передана в целевую систему |
| UC9 | Сформировать отчёт | Руководитель проекта | Подготовлен отчёт |
| UC10 | Контролировать отклонения | Руководитель проекта | Выявлены отклонения |
