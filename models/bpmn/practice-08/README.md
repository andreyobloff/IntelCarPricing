# Практика 08 — BPMN-процесс 1

## Процесс

**Формирование рекомендованной цены автомобильной продукции.**

## Назначение

Модель описывает процесс подготовки данных, расчёта рекомендованной цены, проверки ограничений маржинальности и передачи результата на бизнес-проверку.

## Состав артефактов

| Файл | Назначение |
|---|---|
| `price-recommendation-process.mmd` | Визуальная BPMN-like диаграмма процесса |
| `price-recommendation-process.bpmn` | BPMN XML-модель для импорта/проверки |
| `process-documentation.md` | Документирование процесса, дорожек, задач и данных |
| `data-structure.csv` | Структура данных процесса |
| `sample-data.csv` | Пример строк данных |
| `element-count.csv` | Подсчёт элементов BPMN |
| `validation-report.md` | Отчёт о валидации модели |

## Соответствие заданию

Модель содержит 3 дорожки, стартовое и конечное событие, задачи разных типов, развилки, хранилище данных, объект данных, подпроцесс, структуру данных, пример данных и отчёт валидации.
