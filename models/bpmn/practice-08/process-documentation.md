# Документирование BPMN-процесса практики 08

## Процесс

Формирование рекомендованной цены автомобильной продукции.

## Цель

Описать управляемый процесс подготовки рекомендованной цены на основе продаж, каталога продукции, остатков, рыночных цен, себестоимости и ограничений маржинальности.

## Участники и дорожки

| Дорожка | Ответственность |
|---|---|
| Коммерческий отдел | Инициирует пересчёт, проверяет бизнес-ограничения, утверждает результат |
| Система интеллектуального ценообразования | Загружает данные, рассчитывает индикаторы, формирует цену и обоснование |
| Data Scientist / аналитик | Проверяет аномалии модели и регистрирует версию расчёта |

## Ключевые элементы BPMN

| Тип элемента | Количество | Примеры |
|---|---:|---|
| Start Event | 1 | Требуется пересчёт цены |
| End Event | 2 | Цена готова к публикации; требуется ручная корректировка |
| Task | 8 | Загрузка данных, расчёт цены, проверка ограничений |
| Exclusive Gateway | 2 | Проверка маржинальности, проверка необходимости согласования |
| Data Store | 1 | Хранилище ценовых данных |
| SubProcess | 1 | Расчёт рыночных индикаторов |
| Lane | 3 | Коммерческий отдел, система, аналитик |

## Бизнес-правила

1. Цена не публикуется без проверки маржинальности.
2. При несоответствии ограничениям процесс переводится на ручную корректировку.
3. Каждая рекомендованная цена имеет обоснование.
4. Версия расчёта фиксируется до публикации результата.
5. Данные проходят нормализацию и проверку качества.

## Выходы процесса

- рекомендованная цена;
- обоснование ценового решения;
- журнал версии расчёта;
- признак необходимости ручной корректировки.
