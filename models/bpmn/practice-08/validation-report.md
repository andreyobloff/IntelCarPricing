# Отчёт о валидации BPMN-модели практики 08

## Проверка состава

| Проверка | Статус |
|---|---|
| Есть 2-3 дорожки | Выполнено: 3 дорожки |
| Есть стартовое событие | Выполнено |
| Есть конечные события | Выполнено: 2 события |
| Есть задачи | Выполнено |
| Есть развилки | Выполнено: 2 exclusive gateway |
| Есть хранилище данных | Выполнено |
| Есть подпроцесс | Выполнено |
| Есть структура данных | Выполнено |
| Есть 2-3 строки данных | Выполнено: 3 строки |
| Выполнен подсчёт элементов | Выполнено |

## Логическая проверка

Процесс имеет один основной старт и два допустимых завершения: публикация цены либо переход на ручную корректировку. Основные контрольные точки связаны с маржинальностью и необходимостью согласования.

## Вывод

BPMN-модель практики 08 пригодна для сдачи. Состав элементов и данные соответствуют требованиям задания.
