# Документирование BPMN-процесса практики 09

## Процесс

Согласование и публикация цены автомобильной продукции.

## Цель

Описать процесс проверки рассчитанной цены, её согласования и публикации в целевых каналах.

## Участники и дорожки

| Дорожка | Ответственность |
|---|---|
| Бизнес-эксперт | Проверяет обоснование цены и согласует результат |
| Коммерческий руководитель | Проверяет влияние на маржу и продажи |
| Система публикации цен | Регистрирует утверждённую цену, публикует её и формирует отчёт |

## Ключевые элементы BPMN

| Тип элемента | Количество |
|---|---:|
| Start Event | 1 |
| End Event | 2 |
| Task | 7 |
| Exclusive Gateway | 2 |
| Data Store | 1 |
| SubProcess | 1 |
| Lane | 3 |

## Бизнес-правила

1. Цена публикуется только после проверки обоснования.
2. Влияние на маржу и продажи проверяется до публикации.
3. Утверждённые цены фиксируются в реестре.
4. После публикации формируется отчёт.

## Выходы процесса

- опубликованная цена;
- запись в реестре утверждённых цен;
- отчёт о публикации;
- статус возврата на доработку.
