# Практика 09 — BPMN-процесс 2

## Процесс

**Согласование и публикация цены автомобильной продукции.**

## Назначение

Модель описывает второй BPMN-процесс проекта: проверку рекомендованной цены, согласование коммерческим ответственным, публикацию цены и фиксацию результата.

## Состав артефактов

| Файл | Назначение |
|---|---|
| `price-approval-publication-process.mmd` | Визуальная BPMN-like диаграмма процесса |
| `price-approval-publication-process.bpmn` | BPMN XML-модель |
| `process-documentation.md` | Документирование процесса |
| `data-structure.csv` | Структура данных согласования |
| `sample-data.csv` | Пример данных |
| `element-count.csv` | Подсчёт BPMN-элементов |
| `validation-report.md` | Отчёт о валидации |

## Соответствие заданию

Модель содержит 3 дорожки, события, задачи, развилки, хранилище данных, подпроцесс публикации, структуру данных, 3 строки данных и валидацию.
