# Отчёт о валидации BPMN-модели практики 09

## Проверка состава

| Проверка | Статус |
|---|---|
| Есть 2-3 дорожки | Выполнено: 3 дорожки |
| Есть стартовое событие | Выполнено |
| Есть конечные события | Выполнено: 2 события |
| Есть задачи | Выполнено |
| Есть развилки | Выполнено: 2 exclusive gateway |
| Есть хранилище данных | Выполнено |
| Есть подпроцесс | Выполнено |
| Есть подсчёт элементов | Выполнено |

## Логическая проверка

Процесс начинается после подготовки рекомендованной цены. Положительный сценарий приводит к публикации цены, отрицательный сценарий переводит результат на доработку.

## Вывод

BPMN-модель практики 09 пригодна для сдачи и дополняет модель практики 08 отдельным процессом согласования и публикации.
