# Отчёт по практической работе №3

## Тема

Создание функциональной модели.

## Проект

Интеллектуальное ценообразование на автомобильную продукцию.

## Цель работы

Получить навык создания и редактирования функциональных моделей на примере проекта внедрения системы интеллектуального ценообразования автомобильной продукции.

## Используемая проектная среда

В рамках проекта применяется Git-first подход:

- модель хранится в репозитории как diagram-as-code;
- диаграммы представлены Mermaid-файлами;
- структура функций и стрелок дополнительно зафиксирована в CSV и JSON;
- отчёт хранится в Markdown;
- результат может быть выгружен как единый ZIP-пакет для сдачи.

## Описание предметной области

Компания управляет ассортиментом автомобильной продукции и должна оперативно изменять цены с учётом:

- истории продаж;
- рыночных и конкурентных цен;
- остатков продукции;
- себестоимости;
- целевой маржинальности;
- коммерческой стратегии;
- экспертных ограничений.

Система интеллектуального ценообразования должна формировать рекомендованные цены и предоставлять обоснование ценовых решений.

## Контекстная диаграмма A-0

Контекстная функция:

**Управлять интеллектуальным ценообразованием автомобильной продукции**

| Категория | Элементы |
|---|---|
| Входы | История продаж, каталог продукции, остатки, рыночные цены, себестоимость |
| Управление | Ценовая политика, ограничения маржинальности, коммерческая стратегия, требования к данным, регламент согласования |
| Механизмы | Руководитель проекта, системный аналитик, Data Scientist, backend-разработчик, бизнес-эксперт, GitHub, данные о ценах |
| Выходы | Рекомендованные цены, отчёт об изменении цен, обоснование решений, журнал расчётов, управленческие отчёты |

## Декомпозиция A0

Функция A0 декомпозирована на пять работ:

1. A1 — Собирать и нормализовать данные.
2. A2 — Анализировать рынок и прогнозировать спрос.
3. A3 — Рассчитывать рекомендованные цены.
4. A4 — Согласовывать и публиковать цены.
5. A5 — Контролировать результат и обновлять модель.

## Декомпозиция A2

Для детализации модели выполнена декомпозиция функции A2:

1. A21 — Сопоставить товары с рыночными аналогами.
2. A22 — Рассчитать рыночные индикаторы.
3. A23 — Оценить спрос и эластичность.
4. A24 — Выявить аномалии данных.
5. A25 — Подготовить аналитический набор признаков.
