# Практическая работа №3 — функциональная модель

## Тема

Создание функциональной модели проекта "Интеллектуальное ценообразование на автомобильную продукцию".

## Назначение модели

Функциональная модель описывает процесс управления интеллектуальным ценообразованием как систему работ, входов, выходов, управляющих воздействий и механизмов.

## Нотация

Используется логика IDEF0:

- Input — входные данные;
- Control — управляющие воздействия;
- Output — выходные результаты;
- Mechanism — ресурсы и средства выполнения;
- Function — функция или работа.

## Использование

Файлы `.mmd` являются diagram-as-code артефактами. Их можно открыть в любом Mermaid-compatible просмотрщике либо хранить как исходный код диаграмм в Git.
