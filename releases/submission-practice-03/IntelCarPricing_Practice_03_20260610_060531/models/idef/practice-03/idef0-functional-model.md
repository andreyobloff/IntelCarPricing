# Функциональная модель IDEF0

## Проект

Интеллектуальное ценообразование на автомобильную продукцию.

## Авторская рамка

Облов Андрей Андреевич, СИИ-23, 3 курс, РАНХиГС ЭМИТ.

## Цель модели

Цель функциональной модели — описать деятельность по управлению интеллектуальным ценообразованием автомобильной продукции через функции, входы, выходы, механизмы и управляющие воздействия.

## Контекстная функция A-0

**A-0: Управлять интеллектуальным ценообразованием автомобильной продукции**

### Входы

| Код | Вход |
|---|---|
| I1 | История продаж |
| I2 | Каталог автомобильной продукции |
| I3 | Остатки и доступность товаров |
| I4 | Рыночные и конкурентные цены |
| I5 | Себестоимость и закупочные цены |

### Управление

| Код | Управляющее воздействие |
|---|---|
| C1 | Ценовая политика компании |
| C2 | Ограничения маржинальности |
| C3 | Коммерческая стратегия |
| C4 | Требования к качеству данных |
| C5 | Регламент согласования цен |

### Механизмы

| Код | Механизм |
|---|---|
| M1 | Руководитель проекта |
| M2 | Системный аналитик |
| M3 | Data Scientist |
| M4 | Backend-разработчик |
| M5 | Бизнес-эксперт по автомобильной продукции |
| M6 | Репозиторий GitHub |
| M7 | Данные о ценах и продуктах |

### Выходы

| Код | Выход |
|---|---|
| O1 | Рекомендованные цены |
| O2 | Отчёт об изменении цен |
| O3 | Обоснование ценовых решений |
| O4 | Журнал расчётов и версий модели |
| O5 | Управленческие отчёты |

## Декомпозиция A0

**A0: Управлять интеллектуальным ценообразованием автомобильной продукции**

| Код | Функция | Описание |
|---|---|---|
| A1 | Собирать и нормализовать данные | Получение и подготовка исходных данных для расчёта цен |
| A2 | Анализировать рынок и прогнозировать спрос | Оценка рыночной ситуации, спроса и конкурентного окружения |
| A3 | Рассчитывать рекомендованные цены | Применение правил, ограничений и интеллектуальной модели |
| A4 | Согласовывать и публиковать цены | Проверка бизнес-экспертом и передача результата в целевые системы |
| A5 | Контролировать результат и обновлять модель | Мониторинг отклонений, качества рекомендаций и обновление правил |

## Декомпозиция A2

**A2: Анализировать рынок и прогнозировать спрос**

| Код | Функция | Описание |
|---|---|---|
| A21 | Сопоставить товары с рыночными аналогами | Связать внутренние позиции с конкурентными предложениями |
| A22 | Рассчитать рыночные индикаторы | Определить медианную цену, минимальную цену, максимальную цену и разброс |
| A23 | Оценить спрос и эластичность | Оценить чувствительность продаж к изменению цены |
| A24 | Выявить аномалии данных | Найти выбросы, пропуски и некорректные ценовые значения |
| A25 | Подготовить аналитический набор признаков | Сформировать признаки для расчёта рекомендованной цены |

## Управленческий смысл модели

Модель фиксирует, что интеллектуальное ценообразование не является только техническим расчётом. Это управляемый бизнес-процесс, где данные, правила, модели, роли и согласования образуют единую систему.

## Вывод

Функциональная модель создана. Она адаптирована под проект внедрения системы интеллектуального ценообразования на автомобильную продукцию и может использоваться как исходный IDEF0-артефакт для последующих практических работ.
