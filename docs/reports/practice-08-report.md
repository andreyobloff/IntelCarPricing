# Отчёт по практической работе 08

## Тема

Создание BPMN-процесса в рамках проекта интеллектуального ценообразования автомобильной продукции.

## Процесс

Формирование рекомендованной цены автомобильной продукции.

## Цель работы

Построить BPMN-модель с дорожками, задачами, событиями, развилками, хранилищем данных, подпроцессом, атрибутами процесса, структурой данных, примерами строк данных и проверкой модели.

## Созданные артефакты

| Артефакт | Путь |
|---|---|
| BPMN-like диаграмма | `models/bpmn/practice-08/price-recommendation-process.mmd` |
| BPMN XML | `models/bpmn/practice-08/price-recommendation-process.bpmn` |
| Документирование процесса | `models/bpmn/practice-08/process-documentation.md` |
| Структура данных | `models/bpmn/practice-08/data-structure.csv` |

| Валидация | `models/bpmn/practice-08/validation-report.md` |

## Результат

Практическая работа 08 выполнена. Модель адаптирована под проект интеллектуального ценообразования и отражает полный цикл формирования рекомендованной цены.
