# Отчёт по практической работе 09

## Тема

Создание второго BPMN-процесса для проекта интеллектуального ценообразования автомобильной продукции.

## Процесс

Согласование и публикация цены автомобильной продукции.

## Цель работы

Построить второй BPMN-процесс, связанный с результатами расчёта рекомендованной цены: проверка обоснования, коммерческое согласование, публикация цены и формирование отчёта.

## Созданные артефакты

| Артефакт | Путь |
|---|---|
| BPMN-like диаграмма | `models/bpmn/practice-09/price-approval-publication-process.mmd` |
| BPMN XML | `models/bpmn/practice-09/price-approval-publication-process.bpmn` |

| Подсчёт элементов | `models/bpmn/practice-09/element-count.csv` |
| Валидация | `models/bpmn/practice-09/validation-report.md` |

## Результат

Практическая работа 09 выполнена. Модель показывает отдельный процесс согласования и публикации цены после интеллектуального расчёта.
