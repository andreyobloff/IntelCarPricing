# Презентационный портал проекта

## Назначение

Раздел объединяет материалы для демонстрации проекта **«Интеллектуальное ценообразование на автомобильную продукцию»** преподавателю.

## Основные файлы

| Файл | Назначение |
|---|---|
| `presentation-menu.md` | Навигационное меню демонстрации |
| `final-project-presentation.md` | Единый презентационный файл проекта |
| `demo-script.md` | Сценарий устной демонстрации |
| `artifact-index.csv` | Индекс ключевых артефактов |

## Рекомендуемый порядок показа

1. Открыть главную страницу репозитория.
2. Перейти в раздел «Меню демонстрации проекта».
3. Открыть `final-project-presentation.md`.
4. Последовательно показать постановку задачи, планирование, модели, BPMN-процессы, отчёты и готовность проекта.
