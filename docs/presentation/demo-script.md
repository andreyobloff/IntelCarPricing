# Сценарий демонстрации проекта преподавателю

## 1. Вступление

Показать главную страницу репозитория и обозначить тему проекта: интеллектуальное ценообразование на автомобильную продукцию.

Ключевая мысль: репозиторий используется как единая среда управления проектом.

## 2. Меню демонстрации

Открыть раздел `docs/presentation/presentation-menu.md` и показать порядок защиты.

## 3. Постановка задачи

Показать:

- `PROJECT_CHARTER.md`;
- `docs/problem-statement/statement.md`;
- `docs/assignment-map.md`.

## 4. Планирование

Показать WBS, календарь, ресурсы, задачи, базовый план и отчёты.

## 5. Модели

Последовательно показать:

- IDEF0 и IDEF3;
- UML Use Case и Sequence;
- UML Class и Activity;
- BPMN-процессы практик 08 и 09.

## 6. Документирование BPMN

Показать отчёт практики 10 и таблицу документирования.

## 7. Завершение

Показать индекс артефактов и закрытые GitHub Issues как подтверждение готовности.

## Короткая речь

Проект выполнен как связанная система артефактов. Каждая практическая работа имеет результат в репозитории, отчёт, модель или таблицу. GitHub используется для хранения, трассировки, управления задачами и демонстрации результатов.
