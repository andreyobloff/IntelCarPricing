# Освоенный объём

**Проект:** Интеллектуальное ценообразование на автомобильную продукцию  
**Назначение:** практическое занятие №2, часть 2.

---

## 1. Назначение

Документ фиксирует анализ освоенного объёма для контролируемого контура практических занятий №1 и №2.

---

## 2. Используемые показатели

| Показатель | Расшифровка | Формула |
|---|---|---|
| PV | Planned Value / плановый объём | Базовая стоимость задачи |
| EV | Earned Value / освоенный объём | `PV × PercentComplete / 100` |
| AC | Actual Cost / фактическая стоимость | Фактические затраты |
| SV | Schedule Variance | `EV - PV` |
| CV | Cost Variance | `EV - AC` |
| SPI | Schedule Performance Index | `EV / PV` |
| CPI | Cost Performance Index | `EV / AC` |

---

## 3. Итоги расчёта

| Показатель | Значение |
|---|---:|
| Planned Value | 361900 у.е. |
| Earned Value | 361900 у.е. |
| Actual Cost | 381900 у.е. |
| Schedule Variance EV | 0 у.е. |
| Cost Variance EV | -20000 у.е. |
| SPI | 1.00 |
| CPI | 0.95 |

---

## 4. Интерпретация

- `SPI = 1.00` означает, что в логике освоенного объёма запланированный объём работ выполнен.
- `CPI = 0.95` означает, что стоимость выполнения хуже baseline: на каждый 1 у.е. фактических затрат освоено 0.95 у.е. плановой ценности.
- Основная причина отклонения — задача `22 — Ввод фактических данных`, где фактическая стоимость выросла из-за увеличения длительности.

## 6. Вывод

Отчёт об освоенном объёме показывает не только факт выполнения, но и экономическое отклонение от baseline. Это делает проектную модель пригодной для управленческого контроля.
