# Ограничения задач

**Проект:** Интеллектуальное ценообразование на автомобильную продукцию  
**Назначение:** практическое занятие №1 и практическое занятие №2, часть 1.

---

## 1. Назначение

Документ фиксирует ограничения задач календарной модели. Ограничения используются только там, где они управленчески оправданы: для вех, контрольных точек, baseline и итоговых отчётов.

---

## 2. Типы ограничений

| Код | Название | Смысл |
|---|---|---|
| ASAP | As Soon As Possible | Как можно раньше |
| MSO | Must Start On | Должна начаться в указанную дату |
| MFO | Must Finish On | Должна завершиться в указанную дату |
| SNET | Start No Earlier Than | Начать не ранее указанной даты |

## 4. Управленческое правило

Ограничения не используются для искусственного исправления ошибок планирования. Если задача не укладывается в срок, сначала проверяются зависимости, ресурсные назначения и длительности. Только после этого допускается жёсткое ограничение.

---

## 5. Вывод

Ограничения применяются ограниченно и обоснованно: они фиксируют контрольные точки проекта, а не скрывают проблемы календарного или ресурсного планирования.
