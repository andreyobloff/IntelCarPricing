# Зависимости задач

## Назначение

Документ фиксирует связи между задачами проекта, включая последовательные и параллельные работы.

## Типы связей

- FS — окончание-начало.
- SS — начало-начало.
- FF — окончание-окончание.
- SF — начало-окончание.

## Источник данных

`project/msproject/exports/tasks.csv`
