# Зависимости задач

**Проект:** Интеллектуальное ценообразование на автомобильную продукцию  
**Назначение:** практическое занятие №2, часть 1.

---

## 1. Назначение

Документ фиксирует связи между задачами проекта, включая последовательные и параллельные работы. Суммарные задачи используются для группировки, но не являются объектами прямого связывания при расчёте зависимостей.

---

## 2. Используемые типы связей

| Тип | Расшифровка | Применение |
|---|---|---|
| FS | Finish-to-Start / окончание-начало | Основной тип связи для последовательных задач |
| SS | Start-to-Start / начало-начало | Для параллельных работ |
| FF | Finish-to-Finish / окончание-окончание | Зарезервировано, не используется в текущем baseline |
| SF | Start-to-Finish / начало-окончание | Зарезервировано, не используется в текущем baseline |

## 5. Вывод

Зависимости сформированы так, чтобы все прямоугольники диаграммы Ганта были связаны, при этом суммарные задачи не используются как искусственные предшественники. Параллельные работы применяются только там, где они не создают перегрузку ресурсов.
