# Базовый план

**Проект:** Интеллектуальное ценообразование на автомобильную продукцию  
**Назначение:** практическое занятие №2, часть 2.

---

## 1. Назначение

Базовый план фиксирует согласованное состояние сроков, длительностей и затрат проекта до ввода фактического выполнения. Он используется как контрольная точка для расчёта отклонений.

---

## 2. Состав baseline

| Артефакт | Назначение |
|---|---|
| `project/msproject/exports/baseline.csv` | Плановые даты, длительности и затраты |
| `project/msproject/exports/actuals.csv` | Фактические даты, длительности, затраты и процент выполнения |
| `project/msproject/exports/variance.csv` | Числовые отклонения от baseline |
| `project/msproject/exports/earned-value.csv` | Показатели освоенного объёма |

---

## 3. Контрольные поля

| Поле | Смысл |
|---|---|
| `BaselineDurationDays` | Базовая длительность задачи |
| `ActualDurationDays` | Фактическая длительность задачи |
| `DurationVarianceDays` | Отклонение длительности: `ActualDurationDays - BaselineDurationDays` |
| `BaselineCost` | Базовые затраты |
| `ActualCost` | Фактические затраты |
| `CostVariance` | Отклонение стоимости: `ActualCost - BaselineCost` |
| `PercentComplete` | Процент завершения |
| `PlannedValue` | Плановый объём |
| `EarnedValue` | Освоенный объём |
| `ScheduleVarianceEV` | Отклонение по освоенному объёму: `EV - PV` |
| `CostVarianceEV` | Стоимостное отклонение по освоенному объёму: `EV - AC` |
| `SPI` | Индекс выполнения сроков: `EV / PV` |
| `CPI` | Индекс выполнения стоимости: `EV / AC` |

---

| Показатель | Значение |

---

## 5. Управленческий вывод

Фактическое отклонение возникло на задаче `22 — Ввод фактических данных`: вместо 1 рабочего дня задача заняла 2 рабочих дня. Так как задача находится на критическом пути, это привело к сдвигу итогового отчёта по практике №2 часть 2.

Стоимостное отклонение составило +20000 у.е., что связано с увеличением фактической длительности задачи 22.

---

## 6. Вывод

Базовый план создан, фактические показатели введены, числовые отклонения рассчитаны. Замечание о невыведенных столбцах отклонений закрыто через `variance.csv`, `earned-value.csv` и отчёт `docs/reports/practice-02-part-2-report.md`.
