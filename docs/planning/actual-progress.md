# Фактическое выполнение

**Проект:** Интеллектуальное ценообразование на автомобильную продукцию  
**Назначение:** практическое занятие №2, часть 2.

---

## 1. Назначение

Документ фиксирует фактическую длительность, процент завершения и фактические затраты по контролируемому контуру практических занятий №1 и №2.

---

## 2. Источники данных

| Файл | Назначение |
|---|---|
| `project/msproject/exports/baseline.csv` | Базовый план |
| `project/msproject/exports/actuals.csv` | Фактическое выполнение |
| `project/msproject/exports/variance.csv` | Отклонения от baseline |
| `project/msproject/exports/earned-value.csv` | Освоенный объём |

---

## 3. Фактическое отклонение

В учебной модели большинство задач выполнено по baseline. Для демонстрации управленческого контроля задано одно содержательное отклонение:

| UID | Задача | Baseline duration | Actual duration | Отклонение | Причина |
|---:|---|---:|---:|---:|---|
| 22 | Ввод фактических данных | 1 день | 2 дня | +1 день | Дополнительная проверка фактических значений перед расчётом отклонений |

---

## 4. Итог по контролируемому контуру

| Показатель | Значение |
|---|---:|
| Процент завершения задач | 100% |
| Количество задач с отклонением длительности | 1 |
| Количество задач с отклонением стоимости | 1 |
| Общее отклонение длительности | +1 рабочий день |
| Общее отклонение стоимости | +20000 у.е. |

---

## 5. Управленческий вывод

Так как задача 22 расположена на критическом пути, увеличение её фактической длительности повлияло на дату завершения контролируемого контура. Это демонстрирует, что проектная модель реагирует на изменения факта, а не является статичной таблицей.

---

## 6. Вывод

Фактическое выполнение введено и связано с baseline. Все отклонения отражены численно, что закрывает замечание о невыведенных числовых показателях отклонений.
