# Календарь проекта

**Проект:** Интеллектуальное ценообразование на автомобильную продукцию  
**Календарь:** `IntelCarPricing Standard`  
**Назначение:** календарное основание для практических занятий №1 и №2.

## 4. Использование календаря в Git-среде

Календарь применяется в следующих артефактах:

- `project/msproject/exports/tasks.csv` — даты начала и завершения задач;
- `project/msproject/exports/baseline.csv` — даты baseline;
- `project/msproject/exports/actuals.csv` — фактические даты;
- `project/msproject/exports/variance.csv` — отклонения по срокам и длительности;
- GitHub Project fields `Start Date`, `Target Date`, `Actual Start`, `Actual Finish`.

---

## 5. Вывод

Календарь задаёт воспроизводимое правило расчёта сроков проекта и закрывает требование практического занятия №1 по настройке рабочего времени, выходных, праздничных дней, неполного рабочего дня и имени календаря.
