# Иерархическая структура работ

**Проект:** Интеллектуальное ценообразование на автомобильную продукцию  
**Версия:** 1.0  
**Назначение:** выполнение практических занятий №1 и №2 по дисциплине «Управление проектами».

---

## 1. Назначение документа

Документ фиксирует иерархическую структуру работ проекта для дальнейшего использования в GitHub Issues, GitHub Projects, CSV-плане и MS Project XML.

WBS используется как основной мост между постановкой задачи, календарным планом, ресурсным планом, baseline и отчётностью.

---

## 2. Верхнеуровневые фазы проекта

| WBS | Фаза | Назначение |
|---|---|---|
| 1 | Инициация и постановка задачи | Зафиксировать тему, цель, границы и исходные требования проекта |
| 2 | Календарное и ресурсное планирование | Сформировать задачи, связи, календарь, ресурсы и критический путь |
| 3 | Контроль исполнения и отчётность | Создать baseline, внести фактические данные и рассчитать отклонения |
| 4 | Функциональное моделирование | Подготовить IDEF0/IDEF3 модели |
| 5 | UML-моделирование | Подготовить use case, sequence, class и activity diagrams |
| 6 | BPMN-моделирование | Подготовить бизнес-процессы проекта |
| 7 | Имитационное моделирование | Сравнить сценарии «КАК ЕСТЬ» и «КАК ДОЛЖНО БЫТЬ» |
| 8 | Управление рисками и итоговая комплектация | Подготовить риски, презентацию и финальный комплект |

## 4. Полный проектный контур

В полном проекте содержится 43 задачи, включая последующие IDEF, UML, BPMN, риски и презентацию. Для практических занятий №1 и №2 критичны первые 27 задач, так как они покрывают постановку задачи, календарное планирование, ресурсы, назначения, baseline, фактическое выполнение, отчёты и числовые отклонения.

Полный перечень задач хранится в `project/msproject/exports/tasks.csv`.

## 6. Вывод

WBS сформирована так, чтобы напрямую закрыть замечания преподавателя: постановка задачи вынесена в отдельный deliverable, отчёты выделены в отдельные задачи, ресурсные конфликты имеют отдельный контур анализа и выравнивания, а отклонения от базового плана рассчитываются численно в отдельных таблицах.
